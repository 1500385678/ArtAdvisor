# 5 维鉴赏讲解模板 · Appraise Template

> ArtAdvisor · 作品鉴赏 · v1.0 · 2026-09-04
> 关联:`/appraise` 接口 · `data/artworks.json` · `data/artists.json`
> 上游认知:张勇《艺术鉴赏图谱》`appreciation_knowledge.md`

---

## 一、设计原则

**5 维拆分的目的**:把"作品好不好"这种主观判断,拆成**可拆解、可对比、可入库**的客观维度,让 LLM 不会只说"很美 / 很有名"。

| 原则 | 说明 |
|------|------|
| **可拆解** | 5 维之间互不依赖,可独立生成 / 独立检索 |
| **可对比** | 同一作品 5 维可与同流派 / 同时代作品横向对比 |
| **可入库** | 每维落到固定字段,JSON 化后进 SQLite / Neo4j |
| **不预设褒贬** | 5 维不预设"好/坏"判断,留给用户 + LLM 综合 |

---

## 二、5 维定义

### 维度 1 · 背景 (Context)

> **作品之外的事实链** — 谁、何时、何地、为何

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `artist_bio` | string | 艺术家该时期生平和创作动机 | "达·芬奇 1503 年受佛罗伦萨商人 Francesco del Giocondo 委托,为其妻丽莎·盖拉尔迪尼绘制肖像" |
| `commission` | string | 委托方 / 创作缘由 / 创作地点 | "私人订件 · 佛罗伦萨 · 后转售法国王室" |
| `historical_event` | string | 同时期重大历史/文化事件 | "文艺复兴盛期,佛罗伦萨共和国的商业与艺术巅峰" |
| `period_position` | string | 在艺术史时间线中的位置 | "High Renaissance (1490s-1527),与米开朗基罗《创世纪》天顶画同期" |

### 维度 2 · 构图 (Composition)

> **画面内的视觉组织** — 怎么"看"到这幅画

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `format` | string | 形制 / 比例 / 视角 | "77×53 cm 竖幅半身像,金字塔式构图" |
| `focal_point` | string | 视觉焦点位置 + 引导路径 | "面部三角区 → 双手 → 远景,视线沿手臂下移" |
| `lines_and_shape` | string | 主要线条 / 几何骨架 | "稳定的金字塔轮廓,双手交叠成底部支撑" |
| `color_palette` | string | 主色 + 配色逻辑 | "暖棕调主导,空气透视处理远景,无明显对比色" |
| `space_depth` | string | 空间层次与纵深处理 | "空气透视(sfumato)模糊远景,人物与背景无明显分界" |

### 维度 3 · 技法 (Technique)

> **画是怎么"做"出来的** — 工艺、材料、笔法

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `medium` | string | 媒材与基底 | "木板油画(Poplar panel + oil)" |
| `process` | string | 创作工序 / 特殊技法 | "底层单色厚涂(verdaccio) → 多层透明釉染(glaze),单色底层决定明暗,釉染决定色彩过渡" |
| `innovation` | string | 技法创新点 / 时代首创 | "首创 sfumato 烟雾法:无明确轮廓线,色层渐变消融边界" |
| `restoration` | string | 后世修复 / 状态记录 | "1956-1962 大规模修复 + 2004 卢浮宫 micro-cracking 3D 扫描" |

### 维度 4 · 影响 (Influence)

> **作品之外的长尾** — 后来谁学了它,学了什么

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `direct_heirs` | string[] | 明确受影响的后世艺术家 | "拉斐尔《弗娜芮娜》/ 安格尔《里维耶夫人》/ 达利《蒙娜丽莎·达利》" |
| `paradigm_shift` | string | 是否构成范式突破 | "将肖像画从'符号性'提升到'心理性'层,定下西方肖像画 500 年基调" |
| `cultural_footprint` | string | 跨领域文化影响 | "杜尚《L.H.O.O.Q.》戏仿 / 沃霍尔丝网复刻 / 小说《达·芬奇密码》/ 流行文化高频 icon" |
| `current_location` | string | 现状 / 馆藏 | "巴黎卢浮宫 6 号厅,玻璃柜恒温恒湿展示" |

### 维度 5 · 争议 (Controversy)

> **作品被讨论的"未决项"** — 学界仍未盖棺的部分

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `attribution` | string | 归属 / 真伪争议 | "1970s 部分学者认为背景山水非达·芬奇手笔;2005 卢浮宫红外扫描确认全幅同一人" |
| `iconography` | string | 图像学解读分歧 | "早期解读为'母性' / 19 世纪浪漫主义解读为'神秘微笑' / 20 世纪女性主义解读为'凝视'权力" |
| `value_judgment` | string | 价值判断分歧 | "20 世纪前被视为'达·芬奇次要作品',1911 卢浮宫失窃事件后全球知名度跃升为'世界第一画'" |
| `open_questions` | string[] | 当下研究未解项 | "为何终身未交付给委托方? / 真实模特是谁? / 双重性别气质是巧合还是达·芬奇刻意?" |

## 三、JSON Schema (对接 `data/artworks.json` + `data/artists.json`)

```json
{
  "artwork_id": "aw-001",
  "artist_id": "ar-001",
  "template_version": "appraise-5dim-v1.0",
  "generated_at": "2026-09-04T03:00:00+08:00",
  "generator": "llm:art-advisor + template:5dim",
  "context": {
    "artist_bio": "...",
    "commission": "...",
    "historical_event": "...",
    "period_position": "..."
  },
  "composition": {
    "format": "...",
    "focal_point": "...",
    "lines_and_shape": "...",
    "color_palette": "...",
    "space_depth": "..."
  },
  "technique": {
    "medium": "...",
    "process": "...",
    "innovation": "...",
    "restoration": "..."
  },
  "influence": {
    "direct_heirs": ["..."],
    "paradigm_shift": "...",
    "cultural_footprint": "...",
    "current_location": "..."
  },
  "controversy": {
    "attribution": "...",
    "iconography": "...",
    "value_judgment": "...",
    "open_questions": ["..."]
  }
}
```

**字段总览**:5 维 × 4 子字段 = 20 个核心字段 + 3 个元字段 = 23 字段。

**与 `artworks.json` 22 字段的关系**:`appraise` 表是**外延表**(1 artwork → 1 appraise),不修改主表 schema,通过 `artwork_id` 关联。

**与 `artists.json` 19 字段的关系**:从 `artists.json` 反查 `artist_id` → `artist_bio` / `cultural_footprint` 字段,避免重复录入。

## 四、生成策略 (LLM Prompt 骨架)

```
你是一位艺术史家,请基于以下作品资料,按 5 维模板输出 JSON:
- 作品: {artwork.title_cn} ({artwork.title_en})
- 艺术家: {artist.name_cn} ({artist.lifespan})
- 年代: {artwork.year_range} · 流派: {artwork.period} · 风格: {artwork.style}

请严格按 5 维各 4 子字段输出,不要预设褒贬,不要省略字段,不要展开成段落。
- context: 4 子字段
- composition: 5 子字段
- technique: 4 子字段
- influence: 4 子字段(含数组)
- controversy: 4 子字段(含数组)

若某子字段信息不足,填 "无明确记载" 而非胡编。
```

**纪律**:
- ❌ 不要用"很美/很震撼/非常有名"等空话
- ❌ 不要把多维信息压在一句话里
- ✅ 信息不足就明说"无明确记载"
- ✅ 跨艺术家对比要标"参照 {其他艺术家} 的 {作品}"

## 五、Phase 1 MVP 集成路径

| 阶段 | 任务 | 依赖 |
|------|------|------|
| **T1** | 把本模板作为 `backend/app/services/appraise.py` 静态资源加载 | 无 |
| **T2** | `/appraise?artwork_id=aw-001` 接口返回上述 JSON 格式 | T1 + artworks.json |
| **T3** | LLM 调用 (Claude / GPT-4o) 按 prompt 骨架填充 5 维 | T2 + LLM API key |
| **T4** | 缓存到 `data/appraise/aw-001.json`,二次请求直接读缓存 | T3 |
| **T5** | 前端 5 维分 Tab 展示,每维 200-400 字 | T4 + React 页面 |

**当前状态**:T1 / T2 阻塞 — `backend/app/services/` 仍空,`/appraise` 仍 15 行桩返回。
